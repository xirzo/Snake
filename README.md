## What is this?

A small snake game, that was written back in june of 2025 to practive **Zig**.

## Build

```sh
git clone https://github.com/xirzo/snake && cd snake
zig build
```

## Running

You can move using *WASD* and spawn new apples with *R*.

> Game is currently unstable, so most features do not work for some reason :)

```sh 
./zig-out/bin/snake
```
